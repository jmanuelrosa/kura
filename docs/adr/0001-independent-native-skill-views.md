# Keep independent native skill views

Kura records one logical project skill set but creates a direct catalog link in every selected harness's documented skill directory.
A default-owned view and a neutral Kura view were rejected because either would make one harness depend on another path or introduce a discovery layer that the harnesses do not document.
The duplication is limited to symlinks, while changing selected harnesses cannot move canonical content or break another harness's view.
